CAMPUS EVENTS WEBSITE

Files included:
- index.html: Home page
- about.html: About page
- events.html: Events listing with search
- event-details.html: Event details page
- schedule.html: Event schedule table
- register.html: Registration form with basic browser validation
- style.css: Shared styling for all pages

HOW TO RUN:
1. Extract this ZIP file.
2. Keep all HTML files and style.css in the same folder.
3. Open index.html in a browser, or open the folder in VS Code and use Live Server.

Notes:
- Event photos load from Unsplash, so an internet connection is needed for the images.
- The registration form is front-end only. It does not store or submit data to a server.
